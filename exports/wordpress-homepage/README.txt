Servisoo Homepage Export for WordPress

Files:
- servisoo-homepage.html = markup only
- servisoo-homepage.css = stylesheet
- servisoo-homepage-inline.html = one-file version (style + markup)
- assets/logo.svg
- assets/hero-construction--S05V5pL.jpg

Recommended use:
1. Upload logo + hero image to the same folder structure or keep relative paths as exported.
2. If your WordPress builder allows only one HTML block, use servisoo-homepage-inline.html.
3. If you can add CSS separately, use servisoo-homepage.html + servisoo-homepage.css.
4. Floating chat in this export is converted to a WhatsApp floating button for WordPress compatibility.

Notes:
- This export is based on the current homepage structure in the React project.
- Interactive React-only behaviors like mobile menu toggling and accordion behavior may need extra JS if you want full parity.
